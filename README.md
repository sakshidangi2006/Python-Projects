# 🐍 Python Projects

A collection of Python projects and scripts ranging from beginner utilities to mini-applications — built to practice and strengthen core Python skills.

---

## 📁 Projects Overview

### 🏦 Bank Management System
A console-based banking application that simulates basic banking operations.
- Create and manage bank accounts
- Deposit, withdraw, and check balance
- Persistent data storage via `data.json`

---

### 📒 Contact Book
A contact management system to store and retrieve personal contacts.
- Add, view, search, and delete contacts
- Data persisted using `data.json`

---

### 💸 Expenses Tracker
Track your daily expenses and manage your budget.
- Log and categorize expenses
- View expense history
- Data stored in `expenses.txt`

---

### 🧮 Calculator (`Calculator.py`)
A simple command-line calculator.
- Supports addition, subtraction, multiplication, and division
- Clean and interactive user interface

---

### 📂 File Handling (`File_Handling.py`)
Demonstrates Python's file I/O capabilities.
- Reading from and writing to files
- Covers common file operations and best practices

---

### 🎯 Number Guessing Game (`Guessing_Number.py`)
A fun interactive number guessing game.
- Computer generates a random number
- Player guesses with hints (too high / too low)
- Tracks number of attempts

---

### ✅ To-Do List (`To_Do_List.py`)
A terminal-based task manager.
- Add, view, and remove tasks
- Simple and lightweight productivity tool

---

### 📰 Fake & Funny Headlines Generator (`fake_and_funny_headlines_generator.py`)
Generates random humorous and fake news headlines.
- Combines random words and templates for comedic effect
- Great for entertainment and creative writing prompts

---

### 🔳 QR Code Generator (`generate_qr.py`)
Generate QR codes from any text or URL.
- Uses the `qrcode` library
- Saves QR code as an image file

---

## 🛠️ Tech Stack

- **Language:** Python 3.x
- **Libraries used:** `qrcode`, `json`, standard library (`os`, `random`, `re`, etc.)

---

## 🚀 Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/sakshidangi2006/Python-Projects.git
   cd Python-Projects
   ```

2. **Run any script directly**
   ```bash
   python Calculator.py
   python Guessing_Number.py
   # etc.
   ```

3. **For QR Code Generator, install the dependency first**
   ```bash
   pip install qrcode[pil]
   python generate_qr.py
   ```
